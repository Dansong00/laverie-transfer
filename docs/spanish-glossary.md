# Spanish wording for staff review

Before launch, a Spanish-speaking Laverie staff member should walk through one transfer from SoHo to East Village and back. Review these terms where they appear in the workflow. Record the reviewer, date, and any wording changes in the go-live thread. Staff review is pending.

| English | Current Spanish | Where to check it |
| --- | --- | --- |
| Batch | Lote | A group of orders traveling together |
| Handoff | Entrega | The history of who moved or received the batch |
| Planned | Planificado | The origin has prepared the batch for dispatch |
| Arriving | Por llegar | East Village is expecting a batch from SoHo |
| Ready for return | Listo para devolver | Processing is complete and the order can go back |
| Returning | De regreso | The batch is on its way back to its origin |
| Acknowledge return | Confirmar la recepción de la devolución | The origin confirms the returned batch is physically there |
| Did not travel | No se trasladó | The order stayed behind when the batch left |
| Contents changed | El contenido cambió. Confírmalo antes de la devolución. | Staff must check the remaining orders |
| Personal detergent | Detergente personal | An order has the customer’s own detergent |
| Step back | Volver a marcar el pedido como recibido / Volver a poner el pedido en proceso | Correct the order’s recorded phase |
| Eligible orders | Pedidos elegibles | Orders available to add to a transfer |

Also try the receive button and read its confirmation aloud, for example “¿Marcar como recibido para el lote SOHO-B123?” Does it clearly say which batch is being received? Check that “Por llegar” and “De regreso” distinguish the outbound and return legs at both stores.
